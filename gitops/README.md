# gitops

Everything inside the cluster, deployed by Argo CD ([ADR 0005](../docs/adr/0005-self-managed-argocd-terraform-owned-root.md)).

| Path | What |
|---|---|
| [`root/`](root/) | The app-of-apps chart the Terraform-owned root app points at. It receives `targetRevision`, `repoURL` and `imageTag`; every child Application it renders must use them, so the whole cluster follows one revision. It renders `root-info` (a ConfigMap recording those values, which CI checks) and one Application per entry in `values.yaml`'s `platform:` map — self-managed Argo CD (`prune: false`), Tetragon (with its export filter), the observability stack (`kube-prometheus-stack`, Loki, Alloy, all in `monitoring`), the mittwald secret-generator, the [`outside-world`](platform/outside-world/) stand-ins and the `demo` Swarm — ordered by sync wave (CRD providers first). Entry keys: `wave`, `namespace`, `prune` (default true), then either `repoURL`/`chart`/`version`/`values` for an upstream chart, `path`/`values` (and `followImageTag`, which sets `global.image.tag` to `imageTag`) for a chart in this repo, or, for Argo CD, `valuesFile`; an optional `ignoreDifferences` is passed through to the Application. Its `values.yaml` also pins Argo CD's own chart. |
| [`platform/argocd/values.yaml`](platform/argocd/values.yaml) | Argo CD's chart values — read by the Terraform bootstrap, and used by the self-managed Argo CD app. |
| [`platform/outside-world/`](platform/outside-world/) | In-cluster stand-ins for the Outside World: `approved-api` (an LLM API stand-in on every allowlist, pinned ClusterIP) and `exfil-sink` (on none; `GET /received` shows what reached it). |
| [`platform/observability/`](platform/observability/) | The glue for the **Swarm activity** dashboard, all in `monitoring`: Alloy's config (`files/config.alloy` — ships Tetragon's Guardrail/exec events and the Agents' [Task events](../protocol/README.md#task-events-logs-not-the-broker) to Loki, labelled `swarm`, `role`, `event_type`, `policy`, `state`), the Loki datasource, a `ServiceMonitor` for Tetragon's metrics, and the dashboard (`files/swarm-activity.json`, loaded by Grafana's sidecar — export edits from the Grafana UI over that file). Nothing is persisted and Prometheus keeps 6 h. `task grafana:ui` opens Grafana (admin / admin). |
